daggre.widget¶

ipywidgets host: render a daggre Graph in Jupyter via anywidget over the widget’s comm.

Widget(graph) hosts the graph in a transports.Session/Server; the transports wire rides the widget’s comm (the same protocol as the web host — only the transport differs). The widget object is itself the transports “connection”. Live updates are pushed by a background pump on the kernel’s event loop; outside a loop, call widget.flush(). anywidget makes this an ordinary ipywidgets DOMWidget, so it composes with any ipywidgets layout.
